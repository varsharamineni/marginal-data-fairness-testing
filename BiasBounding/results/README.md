# results

This folder holds the final figures and tables for the paper. Each figure is saved as both `.png` and `.pdf`.

| Folder | Produced by | Contents |
|---|---|---|
| `synthetic/` | `experiments/synthetic_limit.py`, `experiments/synthetic_figure.py` | CSVs for the experiments (`synthetic_compare`, `_compare_nl`, `_cost`, `_cost_mi`, `_joint`, `_sensitivity`), `results_synthetic.tex`, and the matching figures in `figures/`, including `synthetic_summary` |
| `compas_zehlike/` | `experiments/compas/compas_ranking1.py` | `compas_bounds.csv` and `figures/compas_bounds` |
| `compas/` | an earlier run of the COMPAS ranking script | `compas_bounds.csv` and `figures/compas_bounds` |
| `compas_fair/` | `experiments/compas/compas_replication.py` | `compas_fair_bounds.csv/.png` |
